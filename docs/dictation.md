# Dictation

Prism now includes Whisp's macOS recording, 21-bar waveform and text delivery flow. Configure it in **Settings → Dictation**, record a command hotkey, focus a text field in another app, and press the hotkey. Press the same hotkey again to transcribe using the configured default (clipboard only or paste). Separate recording shortcuts can copy, paste, paste and send, or cancel; Return defaults to paste and send. The command is also searchable as `dictation`, `Whisp`, `받아쓰기` and `음성`.

Cancel with Settings → Dictation → Cancel or Escape. Like Whisp, the overlay displays keyboard hints and passes mouse input through; it has no clickable stop/close buttons. Scoped Carbon hotkeys register the configured combinations only while needed. Single modifier keys reuse Whisp’s flags-changed handling and require Accessibility. Disabled actions are not registered; conflicts are reported and excluded from active hints. Only successfully registered controls appear as active recording hints. Cancellation applies during preparation, recording and transcription; it does not undo a completed insertion. Disabling the command also cancels the current session.

## Configuration and permissions

- macOS 14 or later and Apple Command Line Tools are required for the native build. Swift is compiled into the existing Prism process, so recording uses Prism's permission identity rather than a separate helper.
- Local whisper.cpp is the initial provider. Select an installed `whisper-cli` executable and a `.bin` model. Existing Whisp models in `~/Library/Application Support/Whisp/Models` can be selected without modifying them. This change does not install whisper.cpp or download models.
- Remote providers are OpenAI, Vercel AI Gateway, Groq, xAI and a custom OpenAI-compatible server. The picker loads provider catalogs and keeps manual model IDs in a collapsed advanced section; it does not substitute static availability lists on failure. Realtime-only model IDs are rejected; xAI uses its default file-transcription endpoint without sending a model field.
- OpenAI and Vercel reuse the existing Prism AI Keychain accounts and authorization cache. Other STT providers have separate accounts in the same Keychain service and reuse Prism's `KeySession` behavior. Keys are explicitly saved/deleted and never included in settings JSON or renderer responses. Deleting a shared key also affects AI chat, with confirmation in the UI.
- `Info.plist` declares the microphone purpose, and `Entitlements.plist` includes the [audio-input entitlement](https://developer.apple.com/documentation/bundleresources/entitlements/com.apple.security.device.audio-input) for hardened-runtime signing. Microphone permission is requested only when recording starts. Settings → Permissions shows microphone status and links to macOS settings. Existing Accessibility controls also cover dictation insertion. No Accessibility permission means a clipboard fallback with an explicit message.
- Provider, model, language, prompt, vocabulary and local file paths are saved atomically in `dictation-v1.json` under the existing app config directory. Command hotkeys use the existing command-shortcut manager and conflict handling. Dictation settings are not currently part of the library backup format.

## Runtime and privacy

The recorder produces 16 kHz, mono, 16-bit PCM WAV and samples levels every 40 ms. The nonactivating overlay reuses Whisp's complete view/presenter and waveform formula at up to 45 fps. On macOS 26 it uses `NSGlassEffectView.style = .clear`, no tint, alpha 0.50, and a separate sibling hosting layer. Earlier macOS uses Whisp's material fallback. The capsule is 50 points high, 164 wide without hints, or `min(440, 150 + 90 × hintCount)` with hints. Transcribing is 220 × 50 with status; toasts are 330 × 58. Every window has 12-point margins. The bottom position is `visibleFrame.minY + max(76, visibleFrame.height × 0.14)`. The original 21 bars, 3.25 spacing, amplitude response, 0.16-second smoothing and 0.22-second phase animation are unchanged. It captures the original application and AX text target before showing the overlay. Opening dictation through the launcher can reuse the launcher's remembered target without changing the shared window-management target.

Text delivery in paste mode tries the captured AX element, then the target application's focused element, then activation and Command-V. The Command-V fallback now requires a confirmed text input; without one, it copies without sending paste or Enter. Clipboard-only mode bypasses application activation, AX writes and key events entirely. A terminated target cannot be reused. The paste path rechecks foreground PID, task cancellation and clipboard revision immediately before posting. Sending Command-V is not proof that a particular application accepted the text; app-specific acceptance still needs interactive verification. The last result can be copied again from settings.

Recording is limited to five minutes. Reaching that limit cancels and reports an error, without automatically requesting paid transcription. Transcription has a 180-second deadline; cancellation terminates local subprocesses and cancels remote tasks. Stale completion callbacks cannot start a cancelled session or insert its text. Audio and generated local transcript files are removed on success, error, cancellation and normal shutdown. A hard process kill can bypass cleanup of temporary files.

Remote calls are made only when the user stops a recording for transcription. Requests use an ephemeral session, refuse redirects, bound response bodies, and do not expose provider error bodies. Built-in provider keys cannot be redirected to custom hosts. There are no automatic STT retries. Model discovery uses GET requests only, separately from transcription; public Vercel discovery sends no key. Catalog requests have a 20-second deadline, reject redirects and bound responses to 4 MiB. Dictated clipboard content carries the transient marker respected by Prism's existing clipboard-history filter. The last transcript is held only in process memory.

## Model catalogs

- Vercel: reuse Whisp's public [`GET /v1/models`](https://ai-gateway.vercel.sh/v1/models), require `type=transcription` and `supported_specifications` containing `v4`, preserve preferred order and API pricing. Realtime tags/IDs and `-live` rows are visible but disabled. Prices come exclusively from the response, using duration/hour or input/output per million tokens.
- OpenAI: authenticated [`GET /v1/models`](https://developers.openai.com/api/reference/resources/models/methods/list), intersect returned IDs with documented file-transcription families and dated snapshots. Never treat audio-chat models as STT. The current [`gpt-transcribe` file contract](https://developers.openai.com/api/docs/guides/speech-to-text) uses `languages[]`; legacy models retain `language`. Diarization rows are disabled because this flow does not implement their extra options.
- Groq: authenticated [`GET /openai/v1/models`](https://console.groq.com/docs/models), intersect returned active IDs with its [documented speech-to-text models](https://console.groq.com/docs/speech-to-text).
- xAI: [`/v1/stt`](https://docs.x.ai/developers/model-capabilities/audio/speech-to-text) selects the engine server-side without a model field. Settings explain this fixed endpoint instead of presenting a language-model catalog as STT availability.
- Custom compatible endpoints: GET the configured base's `/models`; only explicit `type=transcription` or `/v1/audio/transcriptions` endpoint metadata establishes a catalog row. Generic IDs/audio modalities cannot prove transcription support, so unknown catalogs show an empty-state explanation and retain manual entry.
- Provider, saved-key and custom endpoint changes invalidate visible results. A request generation/cleanup guard excludes late success and failure responses. Key updates from shared AI settings and other windows also trigger refresh. Endpoint typing is debounced. Loading, errors, empty responses and unavailable saved selections are distinct; failed refreshes never silently restore a hardcoded list. Merely editing an unsaved key does not send it anywhere.

### Modifier double taps across Prism (2026-09-10)

- Launcher, command and application hotkey recorders accept Control, Option, Shift or Command pressed twice. Ordinary combinations still use the existing shortcut parser and registration path. Canonical `DoubleControl`, `DoubleOption`, `DoubleShift` and `DoubleCommand` values persist in the existing launcher/command settings files. Native double-tap IDs occupy a separate 64-bit namespace from Carbon/plugin IDs. Duplicate ownership is rejected; registration or persistence failure keeps the previous binding.
- `ModifierDoubleTapDetector.swift` is copied from Whisp with its MIT notice. The 0.42-second interval starts on release; execution occurs on the next press. Ordinary keys, other modifiers and mouse clicks interrupt the sequence. Both native local and global monitors are installed and removed with the active bindings. Apple's [event monitoring documentation](https://developer.apple.com/library/archive/documentation/Cocoa/Conceptual/EventOverview/MonitoringEvents/MonitoringEvents.html) confirms their separate scopes, main-thread delivery and Accessibility requirement for global key events.
- In dictation settings, record the start shortcut by tapping Ctrl twice. Set Paste and Enter to Custom, record Ctrl once, and save the recording shortcuts. The start chord's final release cannot send; a fresh isolated Ctrl press/release sends. Control+A and other modified actions cannot send. Recording modifier actions take precedence over global double taps, with a short reset/cooldown on teardown to prevent sending from reopening dictation.
- While a recorder is active, renewable native capture leases suppress existing double-tap actions. Blur/unmount releases the lease; an abandoned WebView lease expires after two seconds. Begin/end requests are serialized, and failures cancel recording with visible feedback. Global key monitoring requires Prism's Accessibility permission; after granting it, save the shortcut again. No automatic permission prompt or app restart is performed.
