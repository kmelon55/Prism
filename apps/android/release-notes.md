# Prism Android 0.1.1

Customize the launcher with matte depth or background-refracting Liquid Glass, and browse apps by category from either screen edge.

- Choose Flat, Matte depth, or Liquid Glass independently of original or themed app icons. Liquid Glass uses a built-in background or an imported photo and requires Android 13 or newer.
- Browse automatically assigned categories such as food, maps, utilities, productivity, shopping, and media. Change an app's category manually or restore automatic classification.
- Open recently used apps from the same side index. Recent usage reflects apps and shortcuts launched through Prism.
- Keep the selected group near 35% of the screen while holding the index, then reveal the surrounding list on release. Reduce repeated layout work during dragging and preserve the selected app's position.
- Swipe horizontally between widgets, with the selected page and each widget's height preserved.
- Manage favorite additions, removals, and ordering in one screen. Show the home add control only when favorites are empty or home editing is active.

Download `Prism-Android-0.1.1.apk`, or use the Obtainium link below. Existing signed Android installations update in place with the same application ID and signing certificate. Android 9 or newer is required.

Validation includes JVM tests, Android lint, signed release verification, and focused emulator tests for glass rendering, widget paging, persisted settings, category browsing, and drag/release behavior. Physical-device animation performance and Play Store acceptance are not established by these checks.
